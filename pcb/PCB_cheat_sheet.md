### PIN COUNT INDICATORS
(These appear right before the package style suffix)
| INDICATOR | # PINS |
| --- | --- | 
| "K" | 32 |
| "C" | 48 or 52 |
| "R" | 64 or 68 |


### TRAILING VALUE
- 6 = temperature range [ -40degC to +105dedC ]
- Q = SMPS --> effeicient voltage conversion
