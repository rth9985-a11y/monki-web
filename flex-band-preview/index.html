About

A parametric 3D model of a fully flexible fitness band. The shell is clear, so the flex PCB, the display and every package stay visible. The look follows Nothing: transparent body, exposed internals, a dot-matrix screen and one yellow accent.

How to read the model

  • The clear loop is the TPU/silicone shell around the wrist.
  • The amber ribbon is the flex PCB. It runs the full loop, mid-stack.
  • The dot-matrix strip on top is the flexible OLED.
  • The battery and the optical heart-rate sensor sit on the skin side.
  • X-ray makes the shell fainter. Labels names each part.
